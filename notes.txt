LLM (Large Language Model) - AIs that you can chat wuth using text messages
How LLMs work - LLM takes some text as input, analyzes it and predicts a next word that makes sense
How does LLM Pick response
    Greedy Sampling - Pick the highest-probability word
    Random Sampling - Choose a word randomly based on the probability distribution
    Top-k Sampling - Select from a number (k) most probable words
Methods for selection from Probability Distribution
    Temperature Sampling - Adjust the distribution's sharpness ie., Higher temperature = more randomness, Low temperature = more determinstic (closer to greedy sampling)
LLM creates sementic meaning vertor embedding out of each work like
    dog - [0.5, 0.1, 0.3] representing dog characterstic like 0.5 can be fluffyness (is how fluffy it is), mammalness (warm blodded mammals), socialness (enjoy interacting with others)
    in real, sementic vertor embedding does not follow a set of order that first index represents fluffyness, it can be somthing else
Now for a sentence like The dog ran quickly, if wanna make connection between two adjecent word like quickly is assocaited with ran, but we also wanna make association with dog as that states what ran quickly
    so to overcome this, each word gets a new vector embedding representing context ie.,
    this new vector embedding also stores the position information like word dog is 2 word behind quickly 
    key - what context do i have
        (dog) [0.54, 0.36, 0.74]
    query - what context am i looking for
        (quickly) [0.22, 0.64, 0.73]
Context vertic embedding (1000's of number long) are lot smaller in size compared to sementic meaning vector embedding (100's of number long)
Vector is an array of number and can also be coordinate in a point system
Scores are calculated using dot product
    dot product is calculated by drawing a perpendicular line (90 degree angle) from dog context line to quickly context line in a line graph 
    so now the length of the quickly context line from zero to that perpendicular line is the score, ie., how much they overlap
    score is normalized between 0 and 1 or in percentage and then the final score is overlapping length divide by total query length
    dot product calculation lets take key (dog) [0.54, 0.36, 0.74] and query (quickly) [0.22, 0.64, 0.73]
        so dot product is (dog[0] * quickly[0]) + (dog[1] * quickly[1]) + (dog[2] * quickly[2])
        ie., (0.54 * 0.22) + (0.36 * 0.64) + (0.74 * 0.73) = single number score
    higher the score, the more similar they are or it is more likely to select that word
Now the we have dot product between words key and query, we will add them to the original sementic meaning vertor embedding to reflect our finding
    we will create a new vector embedding to represent what you should get from me to encode my context and call it value vector embedding
    ie., embed what context dog would give 
    value (dog) [0.12, 0.84, 0.51]
    value (quickly) [0.62, 0.24, 0.33]
Then we put this value vector embedding thorugh a neural network called feed-forward
    which strengthen the important context in value vector embedding and deminish the less important context in value vector embedding
    so now quickly have more stronger relation to dog
Key - K (what context do i have)
Query - Q (what context am i looking for)
Value - V (what you should get from me to encode my context)
